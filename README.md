# MainCrafts Responsive Website & Task Manager

A responsive website developed as part of the MainCrafts internship tasks.

The project contains a modern MainCrafts website with multiple pages, a responsive navigation bar, contact form, LocalStorage-based contact submissions, and a Task Manager dashboard.

## Features

### Main Website
- Responsive navigation bar
- Home page
- About page
- Contact page
- Services dropdown menu
- Responsive design for desktop, tablet, and mobile
- Smooth scrolling and UI animations
- Interactive buttons

### Contact Form
- Name validation
- Email validation
- Message validation
- Contact submissions stored in LocalStorage
- Submission confirmation page
- View submitted contacts
- Search submissions by name
- Delete individual submissions
- Clear all submissions

### Task Manager
- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Mark completed tasks as pending
- Search tasks
- Filter tasks:
  - All Tasks
  - Completed
  - Pending
- Task statistics:
  - Total Tasks
  - Completed Tasks
  - Pending Tasks
- Tasks are stored using LocalStorage
- Responsive Task Manager dashboard

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
